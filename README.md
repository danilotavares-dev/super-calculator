# Super Calculator

A clean and efficient calculator application built with Java.

## Overview
SuperCalculadora is a Java-based desktop application developed to perform standard mathematical calculations. The project emphasizes a structured codebase and a straightforward user experience, making it a solid foundation for further feature expansion.

## Features
- Standard arithmetic operations (Addition, Subtraction, Multiplication, Division)
- Clear and intuitive user interface
- Reliable error handling for invalid inputs

## Technologies
- **Language:** Java
- **IDE:** Apache NetBeans
- **Build System:** Ant

## Getting Started

### Prerequisites
- Java Development Kit (JDK) 8 or higher
- Apache NetBeans IDE (recommended)

### Running the Project
1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/SuperCalculadora.git
   ```
2. Open Apache NetBeans.
3. Navigate to `File` > `Open Project` and select the `SuperCalculadora` folder.
4. Click `Run Project` (or press `F6`) to compile and launch the application.
